Daftar Nama Gambar & Direktori (PENTING)
----------------------------------------
Agar gambar bisa muncul, Anda harus membuat folder bernama "assets" (huruf kecil semua) 
sejajar dengan file index.html. Simpan gambar-gambar Anda di dalam folder "assets" tersebut 
dengan nama persis seperti di bawah ini:

1. hero-anime.png      -> (Gambar karakter anime di banner atas/hero section)
2. support-anime.png   -> (Gambar chibi anime di kotak bantuan warna ungu bawah)
3. ml-logo.png         -> (Logo game Mobile Legends)
4. ff-logo.png         -> (Logo game Free Fire)
5. pubg-logo.png       -> (Logo game PUBG Mobile)
6. valo-logo.png       -> (Logo game Valorant)
7. qris-logo.png       -> (Logo QRIS di bagian metode pembayaran)

Struktur Folder akhir Anda akan seperti ini:
- assets/
    - hero-anime.png
    - support-anime.png
    - ml-logo.png
    - ff-logo.png
    - pubg-logo.png
